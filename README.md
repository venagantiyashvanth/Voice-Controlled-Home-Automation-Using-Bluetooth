# Voice Controlled Home Automation Using Bluetooth

## 📌 Project Overview

This project is a Bluetooth-based home automation system that allows users to control electrical appliances using voice commands through a smartphone.

The smartphone converts the user's voice command into data and sends it to the Arduino through the HC-05 Bluetooth module. The Arduino processes the received command and controls the appliance through a relay module.

The system also uses a 16×2 LCD to display the current appliance status.

## 🚀 Features

- Voice-controlled appliance operation
- Bluetooth wireless communication
- Arduino-based control
- Fan ON/OFF control
- LCD status display
- Hands-free operation
- Low-cost implementation
- Simple and easy-to-use system
